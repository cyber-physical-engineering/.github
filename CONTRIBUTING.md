# Contributing

These repositories are prototypes. Issues and pull requests are welcome. There is no release schedule and no promised response time.

Before you open a pull request:

1. Run the repository's tests. Each README gives the command in its quick start.
2. Keep the change small and say what it fixes.
3. Match the file's existing style. Where a formatter or linter runs in CI, run it first.

Every README ends with a limits section. A pull request that removes a limit should also update that section.
