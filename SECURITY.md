# Security

The code in this account's repositories is prototype work. Nobody is on call for it, and there is no fixed response time.

If you find a security problem, use GitHub's private vulnerability reporting on the repository: open its Security tab and choose "Report a vulnerability". That keeps the details private until there is a fix or a note in the README. For anything that is not sensitive, open an issue.

Please include the commit you tested, the steps to reproduce, and what you expected to happen.

There is no release schedule. A confirmed problem is fixed when time allows, or named in the README's limits section until it is.
